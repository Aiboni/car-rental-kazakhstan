# Claude Code Instructions

Read AGENTS.md before starting any task.

This project follows spec-driven development.

## Required Workflow
1. Read the relevant specification.
2. Read the assigned GitHub Issue.
3. Identify requirements and acceptance criteria.
4. Implement only the assigned scope.
5. Write and execute tests.
6. Report completed work and remaining issues.

## Technology Restrictions
- Python FastAPI backend
- PostgreSQL database
- HTML, CSS, JavaScript frontend
- No React, Vue, or Next.js

## Important
Never change business rules without approval.
Never use real payment credentials.
Never commit secrets or personal identity documents.
