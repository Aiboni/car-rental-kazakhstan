# AI Agent Instructions

## Project
Car Rental Marketplace Kazakhstan

## Objective
Build a car rental marketplace for Kazakhstan using
spec-driven AI-native development.

## Technology
- Frontend: HTML, CSS, JavaScript
- Backend: Python FastAPI
- Database: PostgreSQL
- API: REST JSON

## Rules
1. Understand requirements before writing code.
2. Never invent missing business requirements.
3. Ask for clarification when specifications conflict.
4. Work on one GitHub Issue at a time.
5. Use a separate branch for each issue.
6. Follow the approved technology stack.
7. Write automated tests for every important feature.
8. Run tests before marking work as complete.
9. Do not store passwords, secrets, or real identity documents in Git.
10. Do not process real payments in the MVP.
11. Update documentation when behavior changes.
12. Do not close issues until acceptance criteria are met.

## Workflow
Specification -> GitHub Issue -> Implementation
-> Testing -> Review -> Merge -> Close Issue

## Definition of Done
- Acceptance criteria satisfied
- Tests pass
- No known critical bugs
- Documentation updated
- Code reviewed
